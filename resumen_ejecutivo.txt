4. PATRÓN DE CAPTURA DE CAMBIOS
================================================================================

MÉTODO: CRUD_MOD.update_mod()
  Estructura retornada:
  {
    "campo": {
      "old": valor_anterior,
      "new": valor_nuevo
    }
  }

CARACTERÍSTICAS:
  - Solo retorna cambios (old != new)
  - Valida campos requeridos (name, status, duration, character)
  - Normaliza slug
  - Excluye campos auditoría: created_by, updated_by, created_at, is_active
  - Retorna tuple: (mod, changes_dict)

OTROS MÉTODOS CON CAPTURA:
  - approve_mod(): Retorna dict con required_revision (True→False)
  - reject_mod(): Retorna dict con required_revision + rejected flag
  - create_mod(): NO retorna cambios (es creación)
  - delete_mod(): NO retorna cambios (solo marca is_active=False)

CAMPOS DE AUDITORÍA GUARDADOS:
  - created_by, created_at
  - updated_by, updated_at
  - deleted_by, deleted_at (parcial)
  - approved_by, approved_at
  - rejected_by, rejected_at
  - comments (razón rechazo O eliminación)
