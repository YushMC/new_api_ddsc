🔄 FLUJO DE EJECUCIÓN
───────────────────────────────────────────────────────────────────────────────

Ejemplo: Agregar géneros a un mod

  1. Cliente: POST /mods/1/genres {"genre_ids": [1, 2]}
  2. Route valida autenticación
  3. CRUD agrega géneros a BD
  4. CRUD retorna (mod, [Genre1, Genre2])
  5. Route verifica que genres_added no está vacío
  6. background_tasks.add_task(notify_genres_added, mod, genres, user)
  7. ✅ Respuesta 200 enviada INMEDIATAMENTE
  8. En paralelo, background task ejecuta:
     ├─ notify_genres_added() [función wrapper sync]
     ├─ Obtiene/crea event loop async
     ├─ DiscordNotifier.notify_genres_added() [async]
     ├─ _format_embed_genres_added()
     ├─ aiohttp POST webhook
     └─ Discord recibe embed rico

🧪 TESTING RECOMENDADO
───────────────────────────────────────────────────────────────────────────────

1. Agregar géneros:
   curl -X POST http://localhost:8000/mods/1/genres \
     -H "Authorization: Bearer TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"genre_ids": [1, 2]}'

2. Remover géneros:
   curl -X DELETE http://localhost:8000/mods/1/genres \
     -H "Authorization: Bearer TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"genre_ids": [1]}'

3. Verificar en Discord:
   - Debe aparecer embed con color púrpura (agregar)
   - Debe aparecer embed con color rosa (remover)
   - Debe mostrar los géneros correctos
